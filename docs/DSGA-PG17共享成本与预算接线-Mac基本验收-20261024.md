# PG17原生共享成本与预算接线：Mac基本验收

## 原生记账修正

startup_shared_upper_bytes本来已包含主共享段和bootstrap四数组，不能直接再加当前数组。PG17 cbabd5de541a1340ab4675cfc3ef14b3a9372671新增独立SHARED_COST_API1，保留固定主段与初始数组分别上界，并按同一次status快照计算“固定主段+当前登记四数组”。所有求和checked，不增共享目录空间，不改变BufferABI6/旧snapshot/准入结构。主段的preload、按M固定结构、普通/巨页对齐及身份页仍计入；未发布、失败、未知、尚未物理回收数组继续计费。

此范围不包含DSM/查询私有、LFC、OS、Guest池/Host等外层成本，不是完整预算或VM许可。Neon1.11新增neon_dsg_shared_cost()，同样PUBLIC撤权与current/session管理员复核，0参数正式C成员，支持升降级。旧PG/缺能力明确拒绝。Rust严格回执/实际扩展成员和签名核验，GET /dsg/v1/budget/shared走专用scope、no-store/有界观察，不清任何未知请求；初始化只读scope无权调用。

Go相同严格消费者和中心固定GET路由已接线。AS预算结算合同与真实Agent最终ResumeAdmission也消费此成本：必须原完整请求/原生PG提交、同boot/代次、当前隔离floor、Runner/实际内存与分类/聚合预算均成立，再先持久完整准入意图后发送。回复丢失恢复原值只读查询，显式重放与PG重放分开。完整资源生产者/初始启动准入/公开worker/最终VM链仍缺部分，不能写成全功能完成。
