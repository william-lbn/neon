# PG17 Linux首批内存验证归档

这是功能分支的阶段归档，PG17整体尚未完成；不进入PG18/16，不运行未修改的上游check-world、存储、HA等矩阵。
所有业务源码由118从GitHub取得。PG17固定为`79367196a74eef82e67cac917877d2e6271d3e70`。

## 本批修改

- `neon_local`内部ComputeSpec初始化补齐`dynamic_shared_buffers=None`，缺省继续关闭，受管实例仍须显式预算。
- 两个内部C helper的“不支持”分支在ERROR后返回`(Datum)0`，避免误用需要`fcinfo`的SQL宏；ERROR语义不变。
- `neon_walredo`不再显式初始化PG17已移除的可选SLRU成员；静态未指定成员在旧结构仍为NULL。
- 增加`ci/pg17_memory_cases.json`编号目录与`ci/run_pg17_memory_cases.py`。执行器要求非root、准确配套库和注入点；零测试、跳过、subTest失败均不能产生绿色收据。
