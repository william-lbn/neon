# PG17 原创建凭据来源绑定：Mac 交接

本批控制面代码 `e83946fe63c3114d0d5912790cbef37c076a5d7b`，沿用原自有
`codex/dsga-control-plane-v3-20261020`；Neon仍使用原V3汇总分支，仅更新交接
文档。PG17仍fcada44b、Autoscaling仍8e1e，Rust/PG源码与三处PG版本锁未改。
本阶段只做PG17，其他PG暂缓；不构建镜像、不准备/执行部署、不合main。

新增实际创建Render回调，从原Operation计划、真实数据库VM绑定及typed Secret
读取生成安全配置，在Operation锁内固定/核对immutable三键凭据的实际UID和
完整内容域摘要。数据库保存UID/摘要，禁止改写/删除重绑，Config已绑定后不许
首次补认。恢复同源只读、xmin不变；前后检查当前worker lease，不持SQL锁访问
Kube。只返回config.json，签名seed不进入Guest，旧adminVerifier不回落到管理SU。

来源协议覆盖applicationVerifier/probeVerifier/controlSigningSeed，TLS不混入
该immutable来源，完整catalog/公开worker/证书挂载和来源能力回执仍需接线。
回调可供生产typed创建器使用，不等于公开API、所有旧Render路径或整个V3完成。

|---|---|

| 实际生产反向 | 关闭摘要比较确实触发指定来源断言（父/子2fail事件），随后原生产文件逐字节恢复并通过受影响验证 |

typed客户端对应TLS API夹具，不能称为真实K8s/VM或Pageserver存储E2E。
