## 本地复跑边界

TAP 所需 IO-Tty 1.31 与 IPC-Run 20260402.0 从官方 MetaCPAN 获取，先核对官方
release SHA256，再安装到工作区 `build/perl-local`。不修改系统 Perl：

```sh
PERL5LIB="$workspace/build/perl-local/lib/perl5" \
  make -C "$workspace/build/pg17-upstream-latest" -j4 \
  TEMP_CONFIG="$workspace/build/pg17-upstream-91246.conf" check-world
```

`workspace` 为本工作区的绝对路径。configure 必须有 `--enable-tap-tests`，rmgr
必须与被测 PG 对应。关闭 TAP 的命令只用于分别记录原有基础门禁，不能使上述
TAP 失败消失或变成“后续 Linux 验收项”。这些问题在 Mac 可复现，应在后续实现
期间继续定位；解决并完成完整回归前，生产发布门槛保持关闭。

本轮 `install-world` 的 SGML 文档安装因外部 DocBook 4.5 DTD 不可用失败；使用
官方 `install-world-bin` 后代码和扩展安装完成。此环境依赖与上述运行期失败分别记录。
